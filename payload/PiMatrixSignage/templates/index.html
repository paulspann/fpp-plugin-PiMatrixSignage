GPIO / physical controls

Use the three dedicated Hanson rPi-MFC user-input connectors for physical buttons or voltage-free relay contacts.

rPi-MFC inputs: A = CN2 / GPIO6 / header pin 31, B = CN3 / GPIO13 / header pin 33, C = CN4 / GPIO26 / header pin 37. The board is designed to use pull-ups, so use a voltage-free switch/relay contact to ground; never feed 5V/12V into a GPIO input.

Automatic recovery
Safe recovery policy: Pi Matrix Signage will restart its renderer if frame output stalls and can restart fppd.service if FPPD is actually inactive. The systemd service also restarts Pi Matrix Signage if the application process exits unexpectedly. It will never reboot or power off the Pi automatically.
